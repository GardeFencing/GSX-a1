3. Process the dataset
1. Process data integrated in the following form：
  1. The id value cannot be repeated
  2. <image>\n should appear at the beginning of the conversation data in each data set
  3. The address corresponding to "image" needs to contain an image.
  4. The list corresponding to each conversation is a multi-turn conversation, content represents the conversation content, role corresponds to user and represents user input, and role corresponds to assistant and represents model output.

4. LoRA fine-tuning：
4.1 Modify MiniCPM-V/finetue/finetune_lora.sh
  Note: If you want to fine-tune the int4 model, first download the int4 model, and then add "q_lora true \" to the line below the following script "--use_lora true \" and tune vision=false
#!/bin/bash
GPUS_PER_NODE=8 # Set this to the number of GPUs per node on your machine, e.g., 8 for an eight-GPU machine.
NNODES=1 # Set this to the number of nodes you have, e.g., 1 for a single server.
NODE_RANK=0 # Specify which server to use for training.
MASTER_ADDR=localhost
MASTER_PORT=6001

MODEL="/root/ld/ld_model_pretrained/Minicpmv2_6" # Local model path or hugginface id
# ATTENTION: Specify the path to your training data, which should be a JSON file containing a list of conversations.
# See the finetuning section in the README for more details.
DATA="/root/ld/ld_project/MiniCPM-V/finetune/mllm_demo.json" # Training data file path
EVAL_DATA="/root/ld/ld_project/MiniCPM-V/finetune/mllm_demo.json" # Validation data file path
LLM_TYPE="qwen2" 

export NCCL_P2P_DISABLE=1 # Remove this line for GPUs that support NCCL P2P, such as A100.
export NCCL_IB_DISABLE=1 # Remove this line for GPUs like A100.

DISTRIBUTED_ARGS="
    --nproc_per_node $GPUS_PER_NODE \
    --nnodes $NNODES \
    --node_rank $NODE_RANK \
    --master_addr $MASTER_ADDR \
    --master_port $MASTER_PORT
"
torchrun $DISTRIBUTED_ARGS finetune.py  \
    --model_name_or_path $MODEL \
    --llm_type $LLM_TYPE \
    --data_path $DATA \
    --eval_data_path $EVAL_DATA \
    --remove_unused_columns false \ 
    --label_names "labels" \ # Data construction, do not modify this.
    --prediction_loss_only false \ 
    --bf16 false \ # Use bf16 precision for training; suitable for GPUs like 4090, A100, and H100.
    --bf16_full_eval false \ # Use bf16 precision for evaluation.
    --fp16 true \ # Use fp16 precision for training.
    --fp16_full_eval true \ # Use fp16 precision for evaluation.
    --do_train \ # Enable training.
    --do_eval \ # Perform validation during training.
    --tune_vision true \ # Fine-tune the siglip (ViT) module.
    --tune_llm false \ # Fine-tune the large language model module.
    --use_lora true \ # Use LoRA for fine-tuning.
    --lora_target_modules "llm\..*layers\.\d+\.self_attn\.(q_proj|k_proj|v_proj)" \ # Layers where LoRA is inserted, specified using a regular expression. Not recommended to change.
    --model_max_length 2048 \ # Maximum sequence length for training.
    --max_slice_nums 9 \ # Maximum number of slices for the model.
    --max_steps 10000 \ # Maximum number of training steps.
    --eval_steps 1000 \ # Number of steps between each evaluation.
    --output_dir output/output_minicpmv2_lora \ # Directory to save LoRA-trained models.
    --logging_dir output/output_minicpmv2_lora \ # Directory to save logs.
    --logging_strategy "steps" \ # Logging strategy (can also choose 'epoch').
    --per_device_train_batch_size 2 \ # Training batch size per device.
    --per_device_eval_batch_size 1 \ # Evaluation batch size per device.
    --gradient_accumulation_steps 8 \ # Gradient accumulation steps; increase this to reduce `per_device_train_batch_size` when low on memory.
    --evaluation_strategy "steps" \ # Evaluation strategy (can also choose 'epoch').
    --save_strategy "steps" \ # Saving strategy (can also choose 'epoch') works together with `save_steps`.
    --save_steps 10 \ # Save every 10 steps.
    --save_total_limit 10 \ # Maximum number of checkpoints to keep.
    --learning_rate 1e-6 \ # Learning rate.
    --weight_decay 0.1 \ # Weight decay parameter.
    --adam_beta2 0.95 \ # Adam optimizer's beta2 parameter.
    --warmup_ratio 0.01 \ # Warmup ratio, i.e., total training steps * warmup_ratio = warmup steps.
    --lr_scheduler_type "cosine" \ # Learning rate scheduler type.
    --logging_steps 1 \
    --gradient_checkpointing true \ # Gradient checkpointing, recommended to enable to significantly reduce memory usage.
    --deepspeed ds_config_zero3.json \ # Use DeepSpeed ZeRO-3; use ds_config_zero2.json if sufficient memory is available.
    --report_to "tensorboard" # wandb # Use TensorBoard or WandB to track loss.

from peft import PeftModel
from transformers import AutoModel, AutoTokenizer
import os
import shutil

model_type = "/root/ld/ld_model_pretrained/Minicpmv2_6"  # Local model path or openbmb/MiniCPM-V-2.5
path_to_adapter = "/root/ld/ld_project/minicpmv2_6/MiniCPM-V/finetune/output/output_minicpmv2_lora/checkpoint-30"  # Path to the saved LoRA adapter
 merge_path = "/root/ld/ld_project/minicpmv2_6/MiniCPM-V/finetune/output/merge_minicpmv"  # Path to save the merged model

# Ensure that all the original model files are saved to the merge_path directory
def copy_files_not_in_B(A_path, B_path):
    """
    Copies files from directory A to directory B if they exist in A but not in B.

    :param A_path: Path to the source directory (A).
    :param B_path: Path to the destination directory (B).
    """
    # Ensure the directories exist
    if not os.path.exists(A_path):
        raise FileNotFoundError(f"The directory {A_path} does not exist.")
    if not os.path.exists(B_path):
        os.makedirs(B_path)

    # List all files in directory A
    files_in_A = os.listdir(A_path)
    files_in_A = set([file for file in files_in_A if not (".bin" in file or "safetensors" in file)])
    # List all files in directory B
    files_in_B = set(os.listdir(B_path))

    # Find files that are in A but not in B
    files_to_copy = files_in_A - files_in_B

    # Copy files from A to B
    for file in files_to_copy:
        src_file = os.path.join(A_path, file)
        dst_file = os.path.join(B_path, file)
        shutil.copy2(src_file, dst_file)
        print(f"Copied {src_file} to {dst_file}")


# Load the original model
model = AutoModel.from_pretrained(
    model_type,
    trust_remote_code=True
)

# Load the LoRA adapter and attach it to the model
lora_model = PeftModel.from_pretrained(
    model,
    path_to_adapter,
    device_map="auto",
    trust_remote_code=True
).eval()

# Merge the LoRA adapter into the original model, maintaining the same shape as the original MiniCPM-Llama3-V-2_5
merge_model = lora_model.merge_and_unload()

# Save the new merged model, which has the same shape as the original MiniCPM-Llama3-V-2_5
merge_model.save_pretrained(merge_path, safe_serialization=False)

# Load the tokenizer and save it to the same directory as the merged model
tokenizer = AutoTokenizer.from_pretrained(model_type, trust_remote_code=True)
tokenizer.save_pretrained(merge_path)

copy_files_not_in_B(model_type,merge_path)

FAQ
1. What to do when GPU memory is insufficient:
  1. Change full fine-tuning to LoRA fine-tuning.
  2. Decrease per_device_train_batch_size and increase gradient_accumulation_steps accordingly.
  3. Fine-tune only the vision module or the language module in full fine-tuning, i.e., set either --tune_llm or --tune_vision to true.
  4. Use ZeRO stage 3 by specifying --deepspeed ds_config_zero3.json.
  5. Reduce the model_max_length
  6. Use CPU offloading by modifying the MiniCPM-V/finetune/ds_config_zero3.json and MiniCPM-V/finetune/ds_config_zero2.json files.
"zero_optimization": {
        "stage": 2,

        }
2. Why is my training loss 0?
If you are training MiniCPM-V 2.6 and the training loss is 0, please check whether your LLM_TYPE in the bash script is "qwen2".
3. Why can't my trained model inference
Perhaps part of the model code or model configuration file is not saved after training, you can check the difference between the current model save address and the original model save address under the file, the original model exists in the file copy to the current model save address
